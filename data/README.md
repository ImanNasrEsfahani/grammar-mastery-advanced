# Advanced Content Data

This directory is intentionally empty of Intermediate canonical content.

Populate only versioned Advanced outputs in these areas:

- `knowledge/` — lessons, atomic subtopics, dependencies, glossary, source references
- `taxonomy/` — categories, subcategories, controlled tags, mappings, membership rules
- `planning/` — weights, capacities, targets and inventory planning
- `question_authoring/` — authoring policies/catalogues and generation batches
- `question_bank/` — Advanced canonical question-bank sources and manifests
- `calibration/` — post-deploy calibration inputs/outputs
- `product/` — product/navigation data if required by the Advanced instance

Stable IDs must be newly generated for Advanced concepts. Do not reuse Intermediate IDs
merely because a grammar title looks similar.
